# Idle Miners Web

A browser-based idle mining game inspired by Idle Miner mechanics.

## Features

- Multiple mines
- Resource collection
- Backpack system
- Equipment upgrades
- Quests and achievements
- Daily rewards
- Leaderboards
- Offline progress

## Technologies

- HTML5
- CSS3
- JavaScript
- GitHub Pages
